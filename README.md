## How to Use

1. **Open in Browser**
   - Double-click `index.html` to open in your default browser
   - Or right-click and select "Open with" to choose a different browser

2. **View on Local Server** (Recommended)
   - Using Python 3:
     ```bash
     python -m http.server 8000
     ```
   - Using Python 2:
     ```bash
     python -m SimpleHTTPServer 8000
     ```
   - Using Node.js (http-server):
     ```bash
     npx http-server
     ```
   - Then visit `http://localhost:8000` in your browser

3. **Navigation**
   - Click navigation links to scroll to sections
   - Explore each use case card with hover effects
   - Use "Contact Us" button for inquiries

## Customization

### Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #003d7a;     /* Navy blue */
    --secondary-color: #0066cc;   /* Bright blue */
    --accent-color: #ffa500;      /* Orange */
}
```

### Content
Edit the HTML in `index.html` to:
- Update use case descriptions
- Add more use cases
- Modify contact information
- Change government agency branding

### Styling
Modify `styles.css` to:
- Change fonts and sizes
- Adjust colors and gradients
- Update spacing and layout
- Customize responsive breakpoints
